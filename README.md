# NEMO 네티즌모바일 홈페이지

GitHub Pages로 서비스되는 정적 사이트. 커스텀 도메인: **nemobile.kr**

## 페이지 구성
| 파일 | 내용 |
|---|---|
| index.html | 홈(소개) |
| system.html | 시스템 소개 |
| revenue.html | 수익모델 |
| how.html | 운영 방식 |
| stores.html | 매장 안내 |
| cost.html | 비용 안내 |
| faq.html | FAQ |
| contact.html | 문의하기 |
| CNAME | 커스텀 도메인(nemobile.kr) 설정 파일 — 삭제 금지 |

## 수정 방법
각 .html 파일을 직접 열어 텍스트/링크를 수정 후 커밋하면 1~2분 내 자동 반영됩니다.
